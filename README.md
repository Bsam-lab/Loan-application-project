# 🏦 Loan Prediction Model

## 📌 Overview

This project predicts whether a loan application will be approved or not using machine learning techniques.
It uses historical customer data such as income, credit history, and loan amount.

---

## 🎯 Objective

To build a classification model that helps financial institutions make better loan approval decisions.

---

## 📊 Dataset Features

* Gender
* Married
* Dependents
* Education
* Self Employed
* Applicant Income
* Coapplicant Income
* Loan Amount
* Loan Term
* Credit History
* Property Area

---

## ⚙️ Tools & Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Jupyter Notebook

---

## 🧪 Model Used

* Logistic Regression

---

## 📈 Results

* Accuracy: 0.788%
* Model performs well in predicting loan approvals based on financial history.
